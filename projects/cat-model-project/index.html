India Flood CAT Model Project This repository contains a Catastrophe (CAT) modelling project focused on flood risk analysis in India. The project includes the model output, visualizations, and an explanation document describing the methodology, assumptions, and interpretation of results. The CAT model analyses flood risk patterns across different regions of India, providing insights into potential flood impacts. The model explanation PDF walks through the technical approach taken, the data sources used, and how the results should be interpreted by stakeholders and researchers. This project was developed to support better understanding of flood catastrophe risk in India, which is one of the most flood-prone countries in the world. The outputs can be used for risk assessment, insurance modelling, and disaster preparedness planning.

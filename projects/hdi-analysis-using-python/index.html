HDI Distribution Analysis (UNDP 2023 Data)

Objective

Examine whether countries' Human Development Index (HDI) scores differ significantly across development tiers (Low / Medium / High / Very High), using UNDP's 2023 Human Development Report statistical annex as the source dataset.

Data

Source: UNDP Human Development Report 2025 — Statistical Annex, Table 1 (HDI and components) Fields used: Country, HDI value (2023) File: data/HDR25_Statistical_Annex_HDI_Table.xlsx

Method

Loaded and cleaned the raw annex file (removed header/footer rows, coerced HDI to numeric, dropped nulls). Segmented countries into four development tiers based on standard UNDP HDI cutoffs:

Low: HDI ≤ 0.55 Medium: 0.55–0.70 High: 0.70–0.80 Very High: > 0.80

Ran a one-way ANOVA (scipy.stats.f_oneway) to test whether mean HDI differs across tiers. Visualized the distribution within each tier using a boxplot.

Result

F-statistic and p-value confirm HDI differs significantly across tiers (as expected, since the tiers are themselves defined by HDI value — this step is primarily a data-QA / sanity check that the UNDP tier cutoffs cleanly separate the dataset, rather than a novel finding). Boxplot shows spread and outliers within each tier — e.g. dispersion is visibly wider in the "High" tier than in "Very High," suggesting more heterogeneity among mid-tier countries.

Honest limitation / next step

Grouping by HDI and then testing for HDI differences across groups is somewhat circular. A more informative follow-up (not yet done here) would be to test HDI against an independent variable — e.g. correlating HDI with GNI per capita, and identifying countries where the GNI-rank-minus-HDI-rank gap is largest (i.e., countries that over- or under-perform their income level on human development). That column already exists in the raw dataset and is a natural extension of this analysis.
